# 短篇一版漫画

起点：仓库只有说明文件和空的 CodeStable 骨架，没有小说解析、档案或出图实现。

目标：把一篇短篇做成一版可翻的静态漫画。出图前先确认可复用档案；确认后的档案能被下一章接着用，不用重新抽取已确认项。

范围：

- 一篇 1 万到 2 万字的短篇文本。
- 用文本模型通读原文，抽出人物卡、场景卡、本版风格 ID 和故事节拍。人物卡包含人物身份及其服装状态。参考图不由这一步产出，它是 ITEM-2 的能力。
- 按已确认档案和故事节拍写页剧本，生成带分格和对白的页面，并导出可按页翻阅的 PDF。
- 档案某一项或风格 ID 变更并重新确认后，只重画引用记录命中该项的页。

非目标：

- 不实现中篇或长篇的生成、切章和调度。
- 不做动态漫、视频或配音。
- 不在这一程同时产出多种风格。
- 不建版权审查、账号、网站或社区。
- 不训练 LoRA，也不建完整地理数据库。
- 不处理同一人物的年龄阶段切换、伪装成他人或变身。原文若出现，抽取时标为未支持，不写入同一份人物身份。该人物在你改掉这段或明确跳过之前，不能出页。改掉这段后必须重跑抽取，按新草稿重新判定；改源文件本身不算跳过。判定清除后，若故事节拍相对冻结版本有变化，已有页剧本和全部页面失效，整篇重写。
- 不支持故事节拍变更后的局部重画。节拍一旦变更，已有页剧本和页面全部失效。
- 不做三视图，也不做侧视或背视。人物参考图只保留一张正脸。
- 不引入物品卡，也不引入地区建筑卡或背景人物卡。引用记录保持四类 ID。
- 不保证同一原文两次抽取得到完全相同的草稿。抽取质量用评测集衡量，不用确定性衡量。

验收标准：

- 给定一篇 1 万到 2 万字的短篇，任一人物身份、服装状态、场景卡或本版风格 ID 未确认时，不能出页。
- 主人确认人物卡、场景卡和风格 ID 后，得到一版按页顺序可翻、对白可读的 PDF。
- 已确认的人物身份、服装状态、场景卡可被后续章节直接读取，不必从原文重新抽取。带参考图的项连同参考图一并复用；未要求带图的项本来就没有图，新章按该章自己的引用计数重新判定带图要求。
- 变更并重新确认档案中的一项或风格 ID 后，重画集合等于引用记录命中该项的页；未命中的页，其页面图像文件字节不重写。
- 页剧本生成之后再改故事节拍，必须先作废全部页剧本和页面，再整篇重写页剧本。
- 修改人物身份后，其下全部服装状态退回未确认，重新确认前不能出页。
- 页剧本只记录情节、对白和引用记录，不复制外貌或服装描述；出图时从档案读取。
- 出页前，被要求带参考图的项都带有已确认参考图。要求带图的项是人物身份、风格 ID，以及被 2 页以上引用的服装状态和场景卡。缺图等同该项未确认。
- 服装状态或场景卡只被 1 页引用时不要求参考图；引用数升到 2 页以上时，该项退回未确认，须补图并重新确认后才能出页。
- 修改某项文字后，其参考图退回未确认。修改人物身份时，其下全部服装状态和它们的参考图一并退回未确认。
- 抽取由文本模型通读原文完成：输入是原文文本本身，不是预抽取结果，也不是外部给定的结构化结果。
- 未支持判定与抽取同出一趟，按人物给出；正则规则表只作提示，不拍板。在评测样本上，正则命中与已知答案冲突时，结果必须跟已知答案走。
- 无从归属到人物的未支持线索不得被静默忽略：草稿必须把它记为无主线索；只要还有未处理的无主线索，整篇不得出页。
- 未支持状态下，人物身份字段只保留进入该状态之前的样貌，不承载该状态的样貌；变身后、伪装后和年龄阶段切换后的样貌都不写入人物身份，也不另存。三类同此一条。原文没有给出进入该状态之前的样貌时，样貌字段留空，不得用变后的描述填充，也不因此判抽取失败。

## 共享语言与概念边界

- **短篇**：这一程的输入文本，篇幅 1 万到 2 万字。
  - 不包括：中篇、长篇，也不包括短视频。
  - 关系 / 不变量：一篇短篇对应一版漫画和一份档案。
  - 来源：DEC-1、DEC-4
- **抽取**：由文本模型通读原文文本，得出人物卡、场景卡、风格 ID 与故事节拍的草稿。
  - 不包括：整理外部已给定的结构化结果，也不包括按关键词表逐条拼装。
  - 关系 / 不变量：人物、服装、场景、情节顺序和未支持判定出自同一趟通读。不要求同一原文两次抽取结果完全相同。
  - 来源：DEC-7
- **未支持判定**：判断某个人物在全文里是否发生年龄阶段切换、伪装成他人或变身。
  - 不包括：普通换装、正常长一岁，以及只改发型这类样貌小变化；也不包括开玩笑式的扮相，例如「扮成鬼脸」「扮成圣诞老人」。
  - 关系 / 不变量：由抽取那一趟的文本模型按人物给出；正则规则表只作提示，不拍板。结果按人物记录；确有无从归属的线索时，草稿把它记为无主线索，不写入任何人物卡。只要还有未处理的无主线索，整篇不得出页。
  - 来源：DEC-7
- **无主线索**：草稿里记录的一条无从归属到任何人物卡的未支持线索。
  - 不包括：挂在某个人物下的未支持判定，也不包括引用记录里的命中。
  - 关系 / 不变量：由抽取那一趟的文本模型给出，不写入任何人物卡，也不进引用记录。只要还有未处理的无主线索，整篇不得出页。
  - 处理方式只有两种：改原文去掉这条线索，或主人明确跳过它。
  - 改原文指换掉产生这条线索的那段文本。改完必须重跑抽取；新草稿只替换尚未确认的抽取结果。已确认的人物身份、服装状态、场景卡、风格 ID 及其参考图不在被替换范围内，不得被这次重跑覆盖或重新抽取；新草稿与档案冲突时以档案为准。故事节拍相对冻结版本有变化的，已有页剧本和全部页面失效，整篇重写，不按「依赖该段」做局部失效。改源文件本身不会把一条线索翻成已处理；只有新草稿里这条线索不再出现，才算处理掉。
  - 跳过写在草稿上的跳过标记里，由确认关卡记录。跳过标记是草稿上的一组记录：每条无主线索、每个未支持人物各记一条，互不覆盖。它不是档案项，也不是引用命中，不进引用记录。
  - 「未处理」指既没有在重跑抽取后消失，也没有被跳过。
  - 来源：DEC-7
- **一版漫画**：按阅读顺序排列、带分格和对白、可导出为 PDF 的静态成稿。
  - 不包括：分镜草稿、动态漫、视频，以及同一短篇的多风格并列版本。
  - 关系 / 不变量：只能引用已确认的人物身份、服装状态、场景卡和风格 ID；对白必须可读。
  - 来源：DEC-1
- **档案**：可复用的事实源，分三块：人物身份、服装状态、场景卡。另有一个本版风格 ID。每一项都可带一张参考图。
  - 不包括：模型上下文窗口、某一次出图的临时提示词、未确认的草稿、故事节拍。
  - 关系 / 不变量：已确认的三块是「谁、穿什么、在哪」的唯一事实源。风格 ID 是「这一版画成什么样」的唯一事实源。故事节拍不是档案的一块。
  - 来源：DEC-2
- **人物卡**：一个人物的确认单位，包含名称、一份人物身份，以及挂在其下的全部服装状态。
  - 不包括：场景卡、风格 ID、故事节拍。
  - 关系 / 不变量：名称是归属和引用的依据，必须唯一。确认状态记在身份和每一套服装状态上，不记成整张卡的一个布尔值。确认人物卡这一个动作，把该卡当前的身份和全部服装状态标为已确认。
  - 来源：DEC-2、DEC-3
- **人物身份**：同一人物不随镜头改变的样貌事实，包括脸型、发型与发色、眼（眼型与瞳色）、显著特征、年龄和体态。一个人物一份身份。
  - 不包括：服装状态、场景、页面风格，以及年龄阶段切换、伪装成他人、变身。
  - 关系 / 不变量：身份不因换装而改写。只修改某一套服装时，身份保持已确认。修改身份时，其下全部服装状态和它们的参考图一并退回未确认，这些服装状态视为一并变更。未支持状态下，身份字段只保留进入该状态之前的样貌，不承载该状态的样貌；变身后、伪装后或年龄阶段切换后的样貌都不写入身份，也不另存。
  - 来源：DEC-2
- **服装状态**：某一人物在某一段情节中的一套穿着。可以有多套，也可以切换。
  - 不包括：人物身份。
  - 关系 / 不变量：必须挂在某个人物身份下。未确认的服装状态不能被页引用。修改某一套后，只把这一套及其参考图退回未确认，同卡的身份和其他服装状态保持原确认状态。身份被修改时，全部服装状态和它们的参考图一并退回未确认。被 2 页以上引用时，该服装状态必须有已确认参考图；引用数按参考图条目里的计数规则计算，升到 2 页以上时该项退回未确认。
  - 来源：DEC-2、DEC-3
- **场景卡**：一个可复用地点，包括名称、建筑外观和原文出处。
  - 不包括：完整地图、地区之间的路径，以及人物身份。
  - 关系 / 不变量：页剧本引用场景卡，不把地点写进人物身份。未确认或修改后未再确认的场景卡不能被页引用。被 2 页以上引用时，该场景卡必须有已确认参考图；引用数按参考图条目里的计数规则计算，升到 2 页以上时该项退回未确认。
  - 来源：DEC-2
- **风格 ID**：这一版页面风格的稳定标识。全篇只有一个。
  - 不包括：人物身份，以及同时存在的多种风格。
  - 关系 / 不变量：在确认关卡选定并确认。未确认不能出页。必须带一张已确认的风格样张。修改风格 ID 时，风格 ID 和样张一并退回未确认，重新确认前不能按新风格出页。
  - 来源：DEC-3
- **参考图**：挂在某个档案项或风格 ID 上、经主人确认的图像锚点。
  - 不包括：页图、分镜草稿、未确认的试画，以及不挂在档案项上的临时参考图。
  - 关系 / 不变量：出页时作为该项的参考输入单独传入。要求带图的项只有三类：人物身份、风格 ID，以及被 2 页以上引用的服装状态和场景卡。只有这些项缺图才等同该项未确认。修改该项文字后，其参考图退回未确认。
  - 来源：DEC-6
  - 引用计数：按引用记录中引用该项的不同页 ID 数量计算。同一页内多个分格重复引用只算 1 页。页剧本重写后按重写后的引用记录重新计算。
- **故事节拍**：从短篇抽出的情节顺序，每条带原文位置。
  - 不包括：人物身份、服装状态、场景卡、风格 ID。
  - 关系 / 不变量：页剧本用它决定「发生什么、先后顺序」，并用它检查不新增原文没有的情节。页剧本不复制外貌或服装描述。它不按人物卡确认。页剧本一旦生成，节拍即冻结；此后再改节拍，已有页剧本和全部页面失效，必须整篇重写，不走局部重画。
  - 来源：DEC-2、DEC-3
- **确认关卡**：主人审阅并确认人物卡、场景卡、风格 ID 和它们的参考图。
  - 不包括：出页，也不包括对成稿画质的事后验收，也不包括确认故事节拍。
  - 关系 / 不变量：任一身份、服装状态、场景卡或风格 ID 未确认，或被要求带图的项缺已确认参考图，就不能出页。只要还有未处理的无主线索，整篇不能出页；主人跳过一条无主线索或一个未支持人物，都由本关卡记入草稿上的跳过标记。修改其中一项后，只将该项退回未确认；修改身份或风格 ID 时按各自条目里的级联规则处理。
  - 来源：DEC-3
- **引用记录**：每一页持久保存的 ID 列表，只含人物身份 ID、服装状态 ID、场景卡 ID、本版风格 ID。
  - 不包括：故事节拍 ID、重新从正文推断出的隐式依赖，以及页面之间共享的派生资源。
  - 关系 / 不变量：档案项和风格 ID 的受影响页只由引用记录决定。故事节拍变更不使用这份记录。
  - 来源：DEC-3
- **受影响的页**：引用记录命中被变更的身份、服装状态、场景卡或风格 ID 的页面。
  - 不包括：引用记录未命中该项的页面，也不包括故事节拍变更。节拍变更时全部页面失效，而不是算出一个受影响子集。
  - 关系 / 不变量：局部重画集合等于受影响的页。修改人物身份时，其下全部服装状态视为一并变更，引用记录命中该身份 ID 或该身份下任一服装状态 ID 的页面都算受影响的页。不变的是未命中页的页面图像文件字节；PDF 允许整份重新封装，不要求旧 PDF 字节不变。
  - 来源：DEC-3

边界场景：输入一篇约 1.5 万字的短篇。系统抽出人物卡、场景卡、风格 ID 和故事节拍，此时没有页图，也没有参考图。主人为人物身份和风格 ID 各出一张参考图并确认；人物卡里的服装状态和场景卡此时可以暂时没有图。页剧本生成后建立引用记录并冻结，按不同页 ID 计数：一套只在 1 页出现的便装不要求配图；另一套在 4 页出现的校服转为要求配图，主人用 ITEM-2 的参考图能力补图并重新确认后才能出页。本程不支持逐页增删或改写页剧本，引用计数只在首次生成或整篇重写时变化：若整篇重写后某套服装从 1 页变成 3 页，该项退回未确认，补图并重新确认前不能出页，且重写已使旧页面全部失效。若再改某套便装的文字，只把这套及其参考图退回未确认，身份和其他服装仍保持已确认；重新确认后只重画引用记录含这套便装的页，其余页的图像文件字节不变。若改的是人物身份，其下全部服装状态和参考图一并退回未确认，引用记录命中该身份或该身份下任一服装状态的页都重画。若改的是风格 ID，风格 ID 和样张一并退回未确认，重新确认后所有引用该风格的页都重画。若改的是故事节拍，全部页剧本和页面作废，整篇重写。PDF 可以重新封装。下一章直接读取已确认的身份、服装状态和场景卡，不从原文重抽这些已确认项；带参考图的项连同参考图一并复用，未要求带图的项本来就没有图，新章按该章自己的引用计数重新判定带图要求。

## 关键决策

- **DEC-1 · 交付物是一版静态漫画**：要分格、对白和可翻的 PDF，不是分镜草稿或视频。理由：主人选定这一程的完成物。
- **DEC-2 · 稳定的是档案**：人物身份、服装状态、场景卡分开保存，供后续章节复用。故事节拍只负责情节顺序，不并入这三块。带参考图的项连同参考图一起复用；未要求带图的项本来就没有图，新章按该章自己的引用计数重新判定带图要求。理由：主人要求加长或换章时不用重新抽取设定。
- **DEC-3 · 先确认再出页**：确认单位是人物卡、场景卡和风格 ID。人物卡包含身份和服装状态，但确认状态记在每一项上。未确认不能出图。修改身份时，其下全部服装状态退回未确认。其他档案项或风格 ID 变更后，只将该项退回未确认，并只重画引用记录命中的页。故事节拍变更不走局部重画，已有页全部失效。标为未支持的年龄切换、伪装或变身，在主人改掉或明确跳过之前，该人物不能出页；改掉后必须重跑抽取并按新草稿重新判定，未判定清除前仍不能出页。只要还有未处理的无主线索，整篇不能出页。理由：主人要求有确认关卡，并在审查遗留上做了这三项裁决。
- **DEC-4 · 只实现短篇**：中篇和长篇不在本程实现。档案仍必须能被后续章节读取。理由：主人要求先稳定短篇，再加长。
- **DEC-5 · 不做版权门**：本程按个人测试处理，不增加权利审查流程。理由：主人明确排除。
- **DEC-6 · 参考图是确认的一部分**：人物身份带一张正脸参考图；风格 ID 带一张风格样张；服装状态和场景卡被 2 页以上引用时才要求参考图。人物身份和风格 ID 的图在确认关卡就要有；服装状态和场景卡在首次确认时允许暂无图，其带图要求在 ITEM-3 建立引用记录后按引用计数判定，并在 ITEM-4 出页前检查。参考图的生成或接收与确认是 ITEM-2 提供的能力，可在页剧本生成后按单项再次调用。引用计数按引用记录中引用该项的不同页 ID 数量计算，且只在页剧本首次生成或整篇重写时确定；本程不支持逐页增删或改写页剧本。参考图可由工具依档案文字生成，也可由主人自带。不做三视图，不引入物品卡。理由：档案原本只有文字，而 ITEM-4 已要求按参考图分开传入；主人逐项选定。
- **DEC-7 · 抽取由文本模型做，正则只作提示**：人物、服装、场景、情节顺序和未支持判定都由文本模型通读原文得出，同出一趟；正则规则表降级为提示，不再拍板。理由：识别谁是谁、哪件衣服属于谁、哪里换了样貌阶段都是语义判断，关键词表在改写说法上既会漏判也会误判；而模型本来就要通读全文，多问一句几乎不增加成本。主人逐项选定。

## 子项契约

- ITEM-1：`cs-feat`。用文本模型通读一篇短篇，抽出人物卡草稿、场景卡草稿、一个风格 ID 草稿和故事节拍。无依赖。验收要点：抽取的输入是原文文本本身，人物、服装、场景、情节顺序和未支持判定出自同一趟通读，不是整理外部给定的结构化结果；身份、服装状态、场景卡、风格 ID 分属不同字段；服装状态挂在身份下；人物身份字段包含脸型、发型与发色、眼（眼型与瞳色）、显著特征、年龄、体态；每张人物卡带唯一名称；故事节拍每条有原文位置且不写入档案三块；未支持判定按人物给出，无从归属的线索记为无主线索且不写入任何人物卡；未支持人物的身份字段只保留进入该状态之前的样貌，原文没给就留空，不得用变后描述填充；此步不生成页图，也不生成参考图。设计约束：正式走通用单篇 1 万到 2 万字，不做长篇切分；评测样本是原文节选，不受该篇幅门槛约束。年龄阶段切换、伪装成他人或变身由文本模型判定，正则规则表只作提示；该人物在主人改掉或明确跳过之前不能出页，改掉后必须重跑抽取并按新草稿重新判定；只要还有未处理的无主线索，整篇不得出页。文本模型供应商在本子项内选择，不改变本契约。本子项自带一个小评测集，每条样本是原文节选加已知答案，至少覆盖下面这几条；每条都要给出「该篇是否产生无主线索」「每个人物的未支持判定结果」「人物卡名称集合」三个字段的期望值，涉及未支持人物时再加「身份样貌」的期望值：无主变身句「有人摇身一变，成了狼。」——产生 1 条无主线索，无人物判定结果，名称集合为空，不得新建名为「有人」的人物卡；「她扮成鬼脸逗他笑」——不产生无主线索，「她」判否，名称集合为「她」，无身份样貌期望；「老师扮成圣诞老人来上课」——不产生无主线索，「老师」判否，名称集合为「老师」，无身份样貌期望；「她变成了一名少年」——不产生无主线索，「她」判是，名称集合为「她」，身份样貌期望为空；「他变成了一个大人」——不产生无主线索，「他」判是，名称集合为「他」，身份样貌期望为空；「他换了一副面孔，谁也没认出来」——不产生无主线索，「他」判是，名称集合为「他」，身份样貌期望为空。必须与已知答案对齐的字段是：该篇是否产生无主线索、每个人物的未支持判定结果、人物卡名称集合，以及未支持人物的身份样貌不含变后描述。正则命中与已知答案冲突时，结果必须跟已知答案走。评测集不进入档案，也不进入页。不要求同一原文两次抽取结果完全相同。
- ITEM-2：`cs-feat`。提供确认关卡，主人可修改并确认人物卡、场景卡、风格 ID 和它们的参考图。依赖 ITEM-1。验收要点：任一身份、服装状态、场景卡或风格 ID 未确认时出页被拒绝；人物身份或风格 ID 缺已确认参考图时出页被拒绝；服装状态和场景卡在首次确认时允许暂无参考图，其带图要求留到出页前按引用记录判定；确认人物卡这一个动作，把该卡当前身份和全部服装状态标为已确认；之后修改某一套服装，只将该套及其参考图退回未确认；修改身份时，其下全部服装状态和它们的参考图一并退回未确认；修改风格 ID 时，风格 ID 和样张一并退回未确认；主人可跳过一条无主线索或一个未支持人物，两者都记入草稿上的跳过标记，只要还有未处理的无主线索就拦住整篇出页。设计约束：确认只落在人物卡、场景卡、风格 ID 和它们的参考图上，跳过标记记在草稿上，不算档案项；不要求账号或网站。风格 ID 不写入人物身份。参考图的生成或接收与确认由本步提供，首次确认时覆盖人物身份和风格 ID，也可在 ITEM-3 之后对单项再次调用，用于补齐转为要求带图的服装状态或场景卡；主人可自带一张图替代生成结果。
- ITEM-3：`cs-feat`。按已确认档案和当前故事节拍写出按阅读顺序排列的页剧本，包含分格、对白，以及每页的引用记录。依赖 ITEM-2。验收要点：引用记录里的身份、服装状态、场景卡和风格 ID 都已确认；页剧本不包含外貌或服装描述；情节只来自故事节拍，不新增原文没有的情节；每一页能通过节拍指回原文位置；页剧本生成后故事节拍冻结；页剧本生成后按引用记录统计每项被多少不同页引用，被 2 页以上引用的服装状态或场景卡转为要求带参考图。设计约束：页数按情节决定，不设固定格数。引用记录只保存四类 ID，不保存节拍 ID 或隐式依赖。页剧本一经生成即冻结，不支持逐页增删或改写；要改变引用计数，只能整篇重写页剧本，重写后旧页剧本和全部页面失效，按新引用记录重新计数并重新判定带图要求。节拍在冻结后被修改时，全部页剧本失效。
- ITEM-4：`cs-feat`。按页剧本生成带分格和对白的页面，导出 PDF，并支持只重画受影响的页。依赖 ITEM-3。验收要点：PDF 能按页顺序阅读，对白可读；出图时的外貌和服装来自档案和已确认参考图，不来自页剧本里的描述句；变更并重新确认身份、服装状态、场景卡或风格 ID 后，重画集合等于引用记录命中该项的页，修改身份时命中该身份或其下任一服装状态的页都算；未命中页的页面图像文件字节不重写；允许重新封装 PDF。故事节拍变更时不得走局部重画，必须先整篇重写页剧本。设计约束：出图使用可替换的参考图接口，身份、当前服装、场景和风格样张分开传入；出页前按引用计数检查带图要求，人物身份或风格 ID 缺已确认参考图即拒绝出页，服装状态或场景卡被 2 页以上引用而缺图时拒绝出页，只被 1 页引用时不要求；引用计数只在页剧本首次生成或整篇重写时确定；本项不生成参考图，缺图时调用 ITEM-2 的参考图能力补齐并重新确认后再出页；具体图像供应商在本子项内选择，不改变本契约；对白以可读文本叠到页面上，不依赖模型把字画进图里。风格 ID 未确认时不得出页。标为未支持且未被主人跳过的人物不得出页；只要还有未处理的无主线索，整篇拒绝出页。

## 整体验收

四个子项完成后，用一篇 1 万到 2 万字的短篇走通：抽取由文本模型通读原文完成，不是整理外部给定结果；未支持判定按人物给出，无从归属的线索必须记为无主线索，只要有未处理的无主线索就整篇拦住出页；任一身份、服装状态、场景卡或风格 ID 未确认时不能出页；人物身份或风格 ID 缺已确认参考图时不能出页；服装状态或场景卡被 2 页以上引用而缺图时不能出页，只被 1 页引用时不要求；引用计数只在页剧本首次生成或整篇重写时确定，计数升到 2 页以上时该项退回未确认，用 ITEM-2 的参考图能力补图并重新确认后才能出页；确认后导出可翻 PDF；已确认档案可被后续读取，带参考图的项连同参考图一并复用，未要求带图的项本来就没有图，新章按该章自己的引用计数重新判定带图要求；修改身份会使全部下属服装状态及其参考图退回未确认；变更并重新确认一项后，只重画引用记录命中的页，未命中页的图像文件字节不变；页剧本不保存外貌描述；页剧本一经生成即冻结，不支持逐页增删或改写；页剧本生成后再改故事节拍，则全部页面失效并整篇重写；标为未支持且未跳过的人物不能出页。

## 遗留风险

- 参考图不能保证像素级同一张脸。本程验收档案复用和局部重画，不验收人脸相似度分数。
- 1 万到 2 万字可能产生大量页面，成本和耗时未在本程量化。
- 场景卡只记录单个地点的建筑外观，不保证多个地点形成统一的地区体系。
- 引用记录不追踪隐式共享资源。若实现额外引入共享派生图，那些图的失效不在本程验收内。
- v1 不含物品卡。某物品被 3 页以上引用且承载情节识别时，中篇或长篇再引入。
- 参考图由模型生成时，同一人物的正脸图可能不理想，需要重画循环。
- 抽取质量依赖所选文本模型。换模型或改提示词都会改变草稿，评测集是唯一可比基线。
- 正则规则表降级为提示后，不带常见字样的改写手法靠模型识别。已踩中的误判句和漏判句已写进 ITEM-1 评测集的已知答案，其余漏判风险仍由该评测集覆盖。
